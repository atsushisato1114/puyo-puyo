# math_utils モジュール

整数に関する数学ユーティリティ関数を提供するモジュール。

フィボナッチ数列・素数判定・最大公約数・最小公倍数・素因数分解など、基本的な整数演算を純粋関数として実装する。副作用なし。

**要件**: Python 3.9 以上（`list[int]` 型ヒントを使用）。

> **Note**: 旧ファイル名 `numbers.py` は Python 標準ライブラリの `numbers` モジュールと衝突するため `math_utils.py` に改名した。

### `fibonacci(n) → int`

n 番目のフィボナッチ数を返す（0-indexed、F(0)=0、F(1)=1）。

反復法で実装しているため、再帰上限の制約を受けない。

**パラメータ**

| 名前 | 型 | 説明 |
|------|----|------|
| `n` | `int` | 0 以上の整数インデックス |

**戻り値** `int` — n 番目のフィボナッチ数。F(0)=0、F(1)=1、F(n)=F(n-1)+F(n-2)。

**例外** `ValueError` — `n` が負の整数のとき。

**使用例**

```python
fibonacci(0)   # 0
fibonacci(1)   # 1
fibonacci(7)   # 13
fibonacci(10)  # 55
```

### `is_prime(n) → bool`

n が素数かどうかを判定する。

2 と奇数のみを試算する最適化済み実装（O(√n) / 2）。`n < 2` のとき常に `False` を返す。

**パラメータ**

| 名前 | 型 | 説明 |
|------|----|------|
| `n` | `int` | 判定対象の整数 |

**戻り値** `bool` — `n` が素数のとき `True`、そうでないとき `False`。

**使用例**

```python
is_prime(2)   # True
is_prime(3)   # True
is_prime(15)  # False  (3 × 5)
is_prime(1)   # False
is_prime(-7)  # False
```

### `gcd(a, b) → int`

ユークリッドアルゴリズムで `a` と `b` の最大公約数を返す。

負の整数は絶対値に変換して処理する。`gcd(0, 0)` は 0 を返す（数学的慣例）。

**パラメータ**

| 名前 | 型 | 説明 |
|------|----|------|
| `a` | `int` | 整数（負・ゼロ可） |
| `b` | `int` | 整数（負・ゼロ可） |

**戻り値** `int` — `a` と `b` の最大公約数（常に 0 以上の整数）。

**使用例**

```python
gcd(48, 18)   # 6
gcd(-12, 8)   # 4
gcd(0, 5)     # 5
gcd(0, 0)     # 0
```

### `lcm(a, b) → int`

`a` と `b` の最小公倍数を返す。

`lcm(a, b) = |a| // gcd(a, b) * |b|` で計算する。中間値のオーバーフローを避けるため乗算前に除算する。どちらかが 0 のとき 0 を返す。

**パラメータ**

| 名前 | 型 | 説明 |
|------|----|------|
| `a` | `int` | 整数（負・ゼロ可） |
| `b` | `int` | 整数（負・ゼロ可） |

**戻り値** `int` — `a` と `b` の最小公倍数（常に 0 以上の整数）。どちらかが 0 のとき 0。

**使用例**

```python
lcm(4, 6)    # 12
lcm(0, 5)    # 0
lcm(-3, 7)   # 21
lcm(7, 7)    # 7
```

### `prime_factors(n) → list[int]`

n の素因数を昇順で返す（重複あり）。

試し割り法。2 を別処理したうえで奇数のみを試算する。`n=1` の素因数は存在しないため空リストを返す。

**パラメータ**

| 名前 | 型 | 説明 |
|------|----|------|
| `n` | `int` | 1 以上の正の整数 |

**戻り値** `list[int]` — 素因数のリスト（昇順・重複あり）。`n=1` のとき `[]`。

**例外** `ValueError` — `n` が 1 未満のとき。

**使用例**

```python
prime_factors(12)   # [2, 2, 3]
prime_factors(17)   # [17]
prime_factors(1)    # []
prime_factors(360)  # [2, 2, 2, 3, 3, 5]
```
