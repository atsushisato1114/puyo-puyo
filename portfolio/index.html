Portfolio

成果物

Claude Code を使って実際に構築・実行したプロジェクトのスクリーンショット

01 Web Scraping

ニュース収集エージェント

Claude UI 上でニュースサイト（Yahoo! / NHK）の最新ヘッドラインを自動収集。 WebSearch と WebFetch を組み合わせ、複数ソースをまとめて出力するタスクを実行しています。

  • Claude Code
  • WebSearch
  • WebFetch
02 CLI Automation

CLI パイプライン実行

ターミナルから Claude Code を直接呼び出し、ニュース見出し一覧をテキスト形式で取得。 スクリプト連携を前提とした出力フォーマット制御を実現しています。

  • CLI
  • PowerShell
  • Structured Output
03 Agent Architecture

マルチエージェント構成設計

VSCode 上で SubAgents と Skills のディレクトリ構成を可視化。 industry-researcher・differentiation-builder・text-reviewer の 3 エージェントが それぞれ専用の役割を持つ設計を示しています。

  • SubAgents
  • Skills
  • VSCode
04 Pipeline

3エージェント自動パイプライン

業界調査 → 差別化戦略構築 → 文章添削を 3 エージェントが順番に処理し、 最終成果物（添削済みブログ記事）を自動生成。Must Fix / Should Fix / Nice to Have の構造化フィードバックまで出力します。

  • Multi-Agent
  • Auto Pipeline
  • Text Review

How it works

処理フロー

3 つのエージェントが連携し、業界調査から最終成果物まで一気通貫で処理します

🔍

Phase 1

industry-researcher

WebSearch + WebFetch で業界情報を収集。市場規模・トレンド・競合・課題を構造化レポートとして出力。

→
⚡

Phase 2

differentiation-builder

Phase 1 のレポートを受け取り、競合にない独自ポジショニングと差別化施策を設計して提案。

→
✍️

Phase 3

text-reviewer

Phase 2 の成果物を受け取り、構成・誤字脱字・表現を多角的に添削。Must Fix / Should Fix 形式で出力。
